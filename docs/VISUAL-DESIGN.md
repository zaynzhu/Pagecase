# Website Lists 视觉与交互设计

## Design Read

Reading this as: 面向大量 Chrome 标签用户的 macOS 原生工具，采用安静、可信、资料柜式的实用极简语言，依托 SwiftUI 系统组件与克制的编辑排版。

当前设计仅使用 `minimalist-ui`。网页专属的 hero、Tailwind、滚动章节和营销组件不适用于本产品，已转换为原生窗口、键盘导航和列表微交互。

## 1. 设计推演

### 第一轮

最初方向是温暖单色背景、白色卡片和低饱和标签色，使用常见侧栏加卡片网格。

### 自我批评

这个方向容易成为另一个 Notion 风格模板：

- 大量独立卡片会增加视觉噪声，也浪费小屏幕空间。
- Bento 网格适合营销展示，不适合快速扫描数十个网页。
- Chrome 标签组颜色如果变成大面积背景，会破坏克制感。
- 过度圆角和阴影会让工具显得松软，降低信息密度。

### 修订方向

最终采用“索引资料柜”：

- 页面主体是连续的文档式列表，不是卡片墙。
- Chrome 标签组颜色只表现为 4px 的装订脊线和小型状态标记。
- 快照像抽屉索引，标题使用系统衬线体，数据与快捷键使用等宽体。
- 结构主要依赖空白、1px 分隔和排版层级，不依赖装饰。

这一条彩色装订脊线是产品的视觉签名：它把 Chrome 原生分组语义带入资料库，同时不复制 Chrome 的标签栏外观。

## 2. 视觉令牌

### 浅色模式

| 名称 | 色值 | 用途 |
|---|---:|---|
| Canvas | `#F7F6F3` | 窗口底色 |
| Surface | `#FFFFFF` | 主内容与弹窗 |
| Ink | `#2F3437` | 主文字 |
| Muted | `#787774` | 次级信息 |
| Border | `#EAEAEA` | 1px 分隔 |
| Live tint | `#E1F3FE` | 已连接、实时 |
| Live ink | `#1F6C9F` | 实时状态文字 |
| Safe tint | `#EDF3EC` | 已保存、安全 |
| Safe ink | `#346538` | 成功状态文字 |
| Stale tint | `#FBF3DB` | 数据过期、离线 |
| Stale ink | `#956400` | 警示状态文字 |
| Error tint | `#FDEBEC` | 错误 |
| Error ink | `#9F2F2D` | 错误文字 |

### 深色模式

深色模式保留相同语义，但不简单反色：

- Canvas `#171716`
- Surface `#20201F`
- Ink `#F0EFEC`
- Muted `#A5A29B`
- Border `#30302E`
- 语义色使用相同色相、较低明度的背景与较高明度的文字

### 标签组颜色

Chrome 的九种标签组颜色映射为低饱和 SwiftUI 色。它们只用于装订脊线、组标题圆点和选中态的轻微底色，不用于整块背景。

## 3. 字体

- 页面标题与快照名称：New York 或系统 `.serif`，Semibold。
- 主要界面与网页标题：SF Pro Text / 系统 `.default`。
- 数量、时间、域名和快捷键：SF Mono / 系统 `.monospaced`。
- 主文字不使用纯黑。
- 网页标题最多两行；网址与域名保持单行并截断中部。

不捆绑外部字体，避免增加应用体积与加载开销。

## 4. 主窗口

建议默认尺寸为 `1080 × 700`，最小尺寸为 `860 × 560`。

```text
┌────────────────────────────────────────────────────────────────────┐
│ Website Lists      [ 搜索网页、标签组或快照        ⌘K ]   已连接  │
├───────────────┬────────────────────────────────────────────────────┤
│               │  现在                           保存当前现场       │
│  现在      84 │  Chrome · 2 个窗口 · 刚刚更新                     │
│  快照      12 │                                                    │
│  设置         │  ┃ 开发                                            │
│               │  ┃  GitHub · Pull requests              github.com │
│  来源         │  ┃  本地项目文档                    localhost:3000 │
│  Chrome       │  ┃  API 参考                         developer... │
│               │                                                    │
│               │  │ 未分组                                          │
│               │  │  日历                                  已固定  │
│               │                                                    │
├───────────────┴────────────────────────────────────────────────────┤
│ 数据只保存在本机 · 不会自动关闭或移动 Chrome 标签                  │
└────────────────────────────────────────────────────────────────────┘
```

### 侧栏

- 固定宽度 208px。
- 只包含“现在”“快照”“设置”和浏览器来源。
- 选中项使用浅灰背景和 6px 圆角，不使用彩色胶囊。
- 数量使用等宽字体，不与标题争夺注意力。

### 顶栏

- 搜索是视觉中心，但不做悬浮大胶囊。
- 状态标记紧凑显示“已连接”“数据过期”或“等待 Chrome”。
- 只有当前页面相关的主操作出现在右侧。

### 内容区

- 使用连续列表和分隔线，不套多层卡片。
- 每个标签组只有一个白色表面，圆角 10px，边框 1px。
- 组内行高 48–56px，足以扫描又不会稀疏。
- 活动网页用轻微底色和左侧短标记表示，不改变整行字体颜色。

## 5. 搜索状态

按 `⌘K` 后仍在原窗口内搜索，不弹出覆盖全屏的命令面板。

```text
┌──────────────────────────────────────────────────────────────┐
│ “prisma” 的 5 个结果                                         │
├──────────────────────────────────────────────────────────────┤
│ 现在   Prisma ORM 文档      Chrome › 开发            定位     │
│ 现在   Prisma Studio        Chrome › 本地项目        定位     │
│ 快照   Prisma 迁移指南      后端重构 · 7 月 18 日    打开     │
└──────────────────────────────────────────────────────────────┘
```

- 实时与快照结果不混淆，动作统一使用“定位”与“打开”。
- 搜索词高亮只改变字重，不使用荧光背景。
- 键盘上下键移动选择，Return 执行当前动作，Escape 清空搜索。

## 6. 快照页面

快照列表使用资料柜式两栏布局：

- 左侧为按时间排列的快照索引。
- 右侧为选中快照的窗口、标签组和网页项。
- 快照标题用系统衬线体，时间和数量使用等宽体。
- 删除放在更多菜单中，并要求确认；主界面不出现醒目的红色按钮。

## 7. 设置页面

设置只展示必要信息：

- Chrome 来源名称与连接状态。
- 本地数据目录。
- 扩展、Native Messaging Host 的检测结果。
- 导入与导出入口。
- 永久可见的安全说明：不会自动关闭、移动、挂起或重组标签。

第一版不提供主题、圆角、动画等纯装饰设置。

## 8. 动效与可访问性

- 首次出现使用 180–240ms 的轻微透明度和 6px 位移。
- 列表实时更新不播放入场动画，避免大量标签变化时闪烁。
- 按钮按下只做 0.98 缩放或系统原生按压反馈。
- 遵守“减少动态效果”和“减少透明度”系统设置。
- 所有交互具备键盘路径、清晰焦点和 VoiceOver 标签。
- 正文与背景至少满足 WCAG AA 对比度。
- 不以颜色作为唯一状态表达。

## 9. 应用图标

图标采用温暖骨白底色与深色索引柜轮廓，内部放置蓝、绿、黄三条短装订脊线。无渐变、无文字、无拟物阴影，在 16px 菜单栏与 1024px 应用图标下都能辨认。
